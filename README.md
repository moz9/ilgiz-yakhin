# ILGIZ YAKHIN — portfolio

Русскоязычное портфолио full-stack / AI-разработчика. Сайт объединяет интерактивную 2.5D-карту, быстрый HR-маршрут, шесть доказательных кейсов и две версии резюме.

## Проверки

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run test:e2e`
- `npm run build`

Публичные данные внутренних инструментов ограничены синтетическими примерами. Тест `public-content.test.ts` блокирует внутренние IP-адреса и запрещенные названия.
