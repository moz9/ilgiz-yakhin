# ILGIZ YAKHIN — portfolio

Русскоязычное портфолио full-stack / AI-разработчика с анимированным каталогом из шести кейсов и двумя версиями резюме.

## Проверки

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run test:e2e`
- `npm run build`

Публичные данные внутренних инструментов ограничены синтетическими примерами. Тест `public-content.test.ts` блокирует внутренние IP-адреса и запрещенные названия.
